用 Cursor / MCP / 多窗 Agent 批回测时，最常见的浪费不是「模型不够聪明」，而是**每一轮把完整 simulation / alpha JSON 又灌回对话**。  
一批 8 条 × 多轮迭代，上下文里大半是重复的 checks PASS、完整表达式、settings 垃圾字段——判断用不上，却把可读窗口吃掉。
 

论坛里 SZ83096（裁剪 MCP）、EL94401（simulation summary）已经点过方向。下面是一套**可落地约定 + 即用投影脚本**：raw 永远在磁盘；Agent / 人只看瘦摘要做「交 / 修 / 扔」。
 

## 1. 现象
 

```text
对话里贴一整份 multi-sim / get_alpha_details
下一轮再贴 8 个完整 alpha object
字段表 get_datafields 全量回显
一边等 Retry-After，一边把等待日志刷进 chat
```
 

结果：
 

- 真正用来判断的只有：S / F / TO / margin、非 PASS 的 check、截断表达式、region/delay/neut  
- 其余 70%+ token 在搬运  
- 多轮后模型开始「记错 alpha_id / 看漏 FAIL」——不是能力问题，是噪声太多
 

## 2. 原则一句话
 

**脚本搬数据 + 投影摘要；模型只读摘要做判断。**
 

| 层 | 放哪 | 谁读 |
|---|---|---|
| raw：`backtest_results.json` / alpha details | 磁盘 | 人排查、脚本重跑 |
| decision：`backtest_decision.json` 或 stdout 几行 | 磁盘 + 对话 | Agent / 你 |
| 等限流 / 轮询 | 脚本里 sleep | **不要**进对话 |
 

批量回测优先自己的 runner（multi-sim + 断点续传）；不要为了「方便」用 MCP 把整批结果倒进窗口。
 

## 3. 每条 Alpha 只保留这些
 

```text
alpha_id
expression（截断到 ~160 字符，后面 …）
sharpe / fitness / turnover / margin
key_checks：只留非 PASS（FAIL / PENDING），PASS 默认扔掉
settings：region, universe, delay, decay, neutralization, truncation, maxTrade
classification：见下表
（可选）matches_pyramid / 分区 Sharpe（GLB 三区）
```
 

### classification（给 Agent 的标签）
 

阈值按你区的硬关改；下面是常用 Regular 示意（S≥1.58 且 F≥1.0）：
 

| 标签 | 含义 | 下一步 |
|---|---|---|
| `candidate` | 过线且无 FAIL | 稳健性 / 相关 → 准备交 |
| `checks_pending` | 过线但有 PENDING（常是相关） | 本地 selfcorr / 平台相关 |
| `has_fail_checks` | 有 FAIL | 修硬关或扔 |
| `nearline` | 接近可交 | 小修一轮，别重写故事 |
| `weak` / `failed` / `error` | 弱或失败 | 换结构或换字段，别雕参 |
 

多轮迭代**只累积 decision 几行**（classification + top ids），不要把上一轮 raw 再贴一遍。
 

## 4. 即插即用：`brain_sim_summary.py`
 

批跑结束后，对你的 `backtest_results.json`（list，每项至少有 sharpe/fitness/expression/checks）跑：
 

```bash
python brain_sim_summary.py summarize --results backtest_results.json --stdout
# 同目录写出 backtest_decision.json
```
 

已有 MCP / 网页保存的 alpha details：
 

```bash
python brain_sim_summary.py slim alpha_details.json
```
 

stdout 长这样（对话里只留这种）：
 

```text
[DECISION] n=8 ok=7 ship=2 counts={'candidate': 1, 'nearline': 2, 'weak': 4, 'has_fail_checks': 1}
  candidate S=1.72 F=1.15 TO=0.28 abCDeFgH seed_01
  nearline  S=1.61 F=0.92 TO=0.41 xyZ12345 seed_03
```
 

把下面整段存成 `brain_sim_summary.py`（可与回测脚本同目录）：
 

```python
# brain_sim_summary.py  —— 复制即用
"""BRAIN sim / alpha JSON → 低 token 决策摘要。raw 留磁盘，对话只读投影。"""
from __future__ import annotations
 

import argparse
import json
from pathlib import Path
from typing import Any, Dict, Iterable, List, Optional, Sequence
 

KEEP_SETTINGS = (
    "region", "universe", "delay", "decay",
    "neutralization", "truncation", "maxTrade", "language",
)
# 按你的区域硬关改这两个数
SHIP_SHARPE = 1.58
SHIP_FITNESS = 1.0



def _num(v: Any) -> Optional[float]:
    if v is None or isinstance(v, bool):
        return None
    try:
        return float(v)
    except (TypeError, ValueError):
        return None



def _slim_settings(settings: Optional[dict]) -> dict:
    if not isinstance(settings, dict):
        return {}
    return {k: settings[k] for k in KEEP_SETTINGS if settings.get(k) is not None}



def _key_checks(checks: Any, limit: int = 8) -> List[dict]:
    if not isinstance(checks, list):
        return []
    rows = []
    keep_even_pass = {
        "MATCHES_PYRAMID", "SELF_CORRELATION",
        "PROD_CORRELATION", "POWER_POOL_CORRELATION",
    }
    for c in checks:
        if not isinstance(c, dict):
            continue
        result = (c.get("result") or c.get("status") or "").upper()
        name = c.get("name") or c.get("check") or ""
        if result in ("PASS", "SUCCESS") and name not in keep_even_pass:
            continue
        row = {"name": name, "result": result or None}
        if c.get("value") is not None:
            row["value"] = c["value"]
        if c.get("limit") is not None:
            row["limit"] = c["limit"]
        rows.append(row)
        if len(rows) >= limit:
            break
    return rows



def classify_row(
    sharpe: Optional[float],
    fitness: Optional[float],
    key_checks: Sequence[dict],
    *,
    error: Optional[str] = None,
    success: bool = True,
) -> str:
    if error:
        return "error"
    if not success:
        return "failed"
    fails = [c for c in key_checks if (c.get("result") or "").upper() == "FAIL"]
    pending = [c for c in key_checks if "PENDING" in (c.get("result") or "").upper()]
    if fails:
        return "has_fail_checks"
    s, f = sharpe or 0.0, fitness or 0.0
    if s >= SHIP_SHARPE and f >= SHIP_FITNESS:
        return "checks_pending" if pending else "candidate"
    if s >= SHIP_SHARPE or (s >= 1.0 and f >= 0.8):
        return "nearline"
    return "weak"



def project_backtest_row(row: dict, expr_max: int = 160) -> dict:
    expr = row.get("expression") or row.get("code") or ""
    if isinstance(expr, str) and len(expr) > expr_max:
        expr = expr[: expr_max - 1] + "…"
    sharpe, fitness = _num(row.get("sharpe")), _num(row.get("fitness"))
    is_block = row.get("is") if isinstance(row.get("is"), dict) else {}
    checks = _key_checks(row.get("checks") or is_block.get("checks"))
    success = bool(row.get("success", True))
    err = row.get("error") or row.get("message")
    out = {
        "name": row.get("name"),
        "alpha_id": row.get("alpha_id") or row.get("id"),
        "expression": expr or None,
        "sharpe": sharpe,
        "fitness": fitness,
        "turnover": _num(row.get("turnover")),
        "margin": _num(row.get("margin")),
        "classification": classify_row(
            sharpe, fitness, checks,
            error=err if not success else None, success=success,
        ),
    }
    if checks:
        out["key_checks"] = checks
    slim = _slim_settings(row.get("settings") if isinstance(row.get("settings"), dict) else {})
    if slim:
        out["settings"] = slim
    return out



def project_alpha_details(detail: dict, expr_max: int = 160) -> dict:
    is_block = detail.get("is") if isinstance(detail.get("is"), dict) else {}
    regular = detail.get("regular") if isinstance(detail.get("regular"), dict) else {}
    expr = regular.get("code") or detail.get("expression") or ""
    if isinstance(expr, str) and len(expr) > expr_max:
        expr = expr[: expr_max - 1] + "…"
    sharpe = _num(is_block.get("sharpe") if is_block else detail.get("sharpe"))
    fitness = _num(is_block.get("fitness") if is_block else detail.get("fitness"))
    checks = _key_checks(is_block.get("checks") if is_block else detail.get("checks"))
    out = {
        "alpha_id": detail.get("id") or detail.get("alpha_id"),
        "expression": expr or None,
        "sharpe": sharpe,
        "fitness": fitness,
        "turnover": _num(is_block.get("turnover") if is_block else detail.get("turnover")),
        "margin": _num(is_block.get("margin") if is_block else detail.get("margin")),
        "settings": _slim_settings(detail.get("settings") if isinstance(detail.get("settings"), dict) else {}),
        "key_checks": checks,
        "classification": classify_row(sharpe, fitness, checks),
        "stage": detail.get("stage"),
    }
    return {k: v for k, v in out.items() if v is not None}



def build_decision(rows: Iterable[dict], top_n: int = 15) -> dict:
    projected = [project_backtest_row(r) for r in rows]
    ok = [r for r in projected if r.get("classification") not in ("failed", "error")]
    ok_sorted = sorted(ok, key=lambda x: (-(x.get("sharpe") or -9), -(x.get("fitness") or -9)))
    shippable = [
        r for r in ok_sorted
        if (r.get("sharpe") or 0) >= SHIP_SHARPE and (r.get("fitness") or 0) >= SHIP_FITNESS
    ]
    counts: Dict[str, int] = {}
    for r in projected:
        c = r.get("classification") or "unknown"
        counts[c] = counts.get(c, 0) + 1
    return {
        "n": len(projected),
        "ok": len(ok),
        "shippable_n": len(shippable),
        "classification_counts": counts,
        "top_candidates": shippable[:top_n] or ok_sorted[: min(5, top_n)],
        "top": ok_sorted[:top_n],
    }



def print_decision_stdout(decision: dict, max_lines: int = 12) -> None:
    print(
        f"[DECISION] n={decision.get('n')} ok={decision.get('ok')} "
        f"ship={decision.get('shippable_n')} counts={decision.get('classification_counts')}"
    )
    for r in (decision.get("top") or [])[:max_lines]:
        print(
            f"  {r.get('classification')} S={r.get('sharpe')} F={r.get('fitness')} "
            f"TO={r.get('turnover')} {r.get('alpha_id')} {r.get('name')}"
        )



def main() -> int:
    p = argparse.ArgumentParser(description="Project BRAIN payloads to low-token summaries")
    sub = p.add_subparsers(dest="cmd", required=True)
 

    s = sub.add_parser("summarize", help="results list JSON → decision JSON")
    s.add_argument("--results", type=Path, default=Path("backtest_results.json"))
    s.add_argument("--out", type=Path, default=Path("backtest_decision.json"))
    s.add_argument("--stdout", action="store_true")
 

    s2 = sub.add_parser("slim", help="slim one alpha-details / results file")
    s2.add_argument("path", type=Path)
 

    args = p.parse_args()
    if args.cmd == "summarize":
        data = json.loads(args.results.read_text(encoding="utf-8"))
        if not isinstance(data, list):
            raise SystemExit("results must be a JSON list")
        decision = build_decision(data)
        args.out.write_text(json.dumps(decision, ensure_ascii=False, indent=2), encoding="utf-8")
        if args.stdout:
            print_decision_stdout(decision)
        else:
            print(f"wrote {args.out} (n={decision['n']} ship={decision['shippable_n']})")
        return 0
    if args.cmd == "slim":
        data = json.loads(args.path.read_text(encoding="utf-8"))
        if isinstance(data, list):
            out = build_decision(data)
        else:
            out = project_alpha_details(data)
        print(json.dumps(out, ensure_ascii=False, indent=2))
        return 0
    return 1



if __name__ == "__main__":
    raise SystemExit(main())
```
 

接入批跑：回测脚本写完 `backtest_results.json` 后调一次 `summarize`；Agent 规则写成「只读 `backtest_decision.json` / stdout，禁止贴 raw」。
 

## 5. 和 Agent 约定的四条硬规则
 

1. **批量用脚本**，不要用 MCP `create_multi_simulation` 把整批灌进对话再人工盯  
2. **详情先投影**：拿到 `get_alpha_details` / submission_check 先 `slim`，对话里只留摘要  
3. **多轮只累 decision**：每轮顶多几行 classification + top ids  
4. **限流在脚本里等**：Retry-After / 轮询日志不进 chat  
 

字段 / 算子列表同理：本地筛完只报候选名与覆盖摘要，别全表回显。
 

## 6. 不会改脚本也先做到
 

1. 批跑结果存文件，对话里手贴时只贴：id、S、F、TO、FAIL 项、截断表达式  
2. PASS 的 check 一律不贴  
3. 同一批不要把完整 JSON 贴第二次——指文件路径即可  
4. 「等 60 秒重试」写在脚本；人/Agent 去做下一件判断
