# Alpha生成脚本 - 质量驱动版本使用指南

## 概述

这是一个**质量优先**的Alpha生成系统，完整流程：

```
生成候选 → 平台模拟 → 质量筛选 → 反馈学习 → 优化策略 → 循环迭代
```

## 核心特性

### ✅ 质量驱动
- 只保存 **质量分数 ≥ 2.0** 的候选（Sharpe + 1.05 × Fitness）
- 平台模拟筛选，不是盲目生成
- 学习高质量策略家族，优先生成

### ✅ 反馈循环
- 跟踪每个策略家族的**通过率**、**平均Sharpe**、**平均Fitness**
- 动态调整权重：高质量家族 ↑，低质量家族 ↓
- 指数移动平均（EMA）平滑反馈，避免过度反应

### ✅ 自相关控制
- **轮次去重**：每轮内 `field_skeleton` 唯一（降低自相关）
- **全局去重**：跨轮次 `exact_hash` 唯一（避免重复模拟）

## 使用方法

### 1. 基础运行（无模拟，仅生成）

```powershell
& .venv/Scripts/python.exe 生成Alpha_质量驱动.py --max-rounds 5 --batch-size 20
```

**适用场景**：
- 测试生成器是否正常
- 快速生成候选（后续手动模拟）

**输出**：无（禁用模拟时不保存）

---

### 2. 质量驱动运行（启用平台模拟）⭐

```powershell
& .venv/Scripts/python.exe 生成Alpha_质量驱动.py --simulate --max-rounds 10 --batch-size 20 --min-quality-score 2.5
```

**适用场景**：
- **生产环境**：持续生成高质量候选
- 循环迭代，越做越好

**流程**：
1. 每轮生成 20 个候选
2. 平台模拟 → 获取 Sharpe/Fitness
3. 只保存质量分数 ≥ 2.5 的候选
4. 更新质量反馈（每个策略家族的表现）
5. 下一轮优先生成高质量家族

**输出**：`高质量Alpha列表.csv`

---

### 3. 长期运行（无限循环）

```powershell
& .venv/Scripts/python.exe 生成Alpha_质量驱动.py --simulate --max-rounds 0 --batch-size 15 --interval 60
```

**参数说明**：
- `--max-rounds 0`：无限循环（Ctrl+C 停止）
- `--batch-size 15`：每轮生成 15 个（避免过快耗尽组合空间）
- `--interval 60`：轮次间隔 60 秒（避免平台限流）

## 质量反馈示例

```
[质量] === 质量反馈 ===
[质量]   momentum: 通过率=15.0% Sharpe=1.28 Fitness=1.05 质量分=29.3
[质量]   reversal: 通过率=8.0% Sharpe=1.15 Fitness=0.92 质量分=19.7
[质量]   fundamental: 通过率=22.0% Sharpe=1.42 Fitness=1.18 质量分=36.2
[质量]   volatility: 通过率=5.0% Sharpe=0.95 Fitness=0.78 质量分=12.8
```

**解读**：
- **fundamental** 家族质量最高（36.2），下一轮会优先生成
- **volatility** 家族质量最低（12.8），下一轮会降低权重
- **反馈循环**自动优化生成策略

## 常见问题

### Q: 为什么每轮只保存1-3个候选？
**A**: 质量驱动。每轮生成20个，但只有通过平台模拟且质量分数 ≥ 2.0 的才会保存。

### Q: 如何提高通过率？
**A**: 
1. 增加 `--batch-size`（更多候选 → 更多机会）
2. 降低 `--min-quality-score`（放宽筛选）
3. 等待反馈学习收敛（前几轮通过率低，后续会提升）

### Q: 平台限流怎么办？
**A**: 增加 `--interval`（轮次间隔），例如 `--interval 120`（2分钟）

### Q: 可以不用平台模拟吗？
**A**: 可以，但失去质量驱动的核心价值。建议：
- 开发/测试：禁用模拟（`--simulate` 不加）
- 生产环境：启用模拟（`--simulate`）
